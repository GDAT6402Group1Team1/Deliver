手机会在步行和驾驶时使用，因此相关对象不能跟着当前 Pawn 一起切换。玩家控制器保留输入和服务器请求，手机界面逻辑放在 UI/Controllers/DeliveryPhoneController，由 HUD 创建和销毁。这与已有任务、快捷栏和交互处理器使用 UObject 的方式一致

各个对象负责什么

对象 职责 主要状态
DeliveryPhoneCallQueueComponent 服务器管理来电队列、接听、挂断和通话时长，向客户端复制 当前电话、通话阶段、开始时间
DeliveryPhoneController 处理手机操作，读取通话内容，协调对白并更新字幕 当前对白编号、来电者名字、已显示的字幕
DeliveryHUD 创建手机处理器，管理多个面板的开关和鼠标模式 OpenPanels 面板集合
手机 Widget 蓝图 生成手机布局，显示内容，响应按钮 控件和显示效果
DeliveryPhoneAudioComponent 监听电话状态，播放铃声、接听、挂断和手机操作音效 铃声音频实例、上次电话状态
DeliveryDialogueVoiceComponent 将台词变成电子语音，并通知当前读到哪个字 语音播放进度
DeliveryPlayerController 接收 IA_TogglePhone，转交手机操作，提供接听和挂断的服务器入口 输入配置、跨角色使用的组件引用

电话队列就是这里的 Model。处理器读取这份已有数据，不重新建立一份电话队列。HUD 的面板集合是本机界面状态，不参与网络复制

按 J 打开手机

void ADeliveryPlayerController::HandleTogglePhonePressed()

Toggle 读取 HUD 中的手机面板状态，改变状态后让原手机蓝图更新显示。开关提示音交给 PhoneAudio 播放。这里保留 PC 的 TogglePhoneUI 蓝图事件作为现有 Widget 的连接入口，事件本身不保存界面状态，也不决定如何播放声音

// 来源：Source/Delivery/UI/Controllers/DeliveryPhoneController.cpp
void UDeliveryPhoneController::Toggle()
{
    if (!Player.IsValid() || !HUD.IsValid()) return;
    if (auto* Audio = Player->FindComponentByClass<UDeliveryPhoneAudioComponent>()) Audio->PlayToggle();

手机自动展开、接听后收起或 Widget 自行关闭时，原蓝图仍可以调用 ReportPhoneUIOpen。这个兼容入口现在把状态转交给处理器，再由 HUD 更新面板集合。新蓝图可通过 GetPhoneController 直接调用 SetOpen、Answer 和 HangUp

面板关闭后，为什么鼠标有时还在

手机和其他界面可能同时打开。每个界面只报告自己的开关状态，HUD 判断是否还有其他面板存在

// 来源：Source/Delivery/UI/DeliveryHUD.cpp
void ADeliveryHUD::SetPanelOpen(FName PanelId, bool bOpen)
{
    if (PanelId.IsNone()) return;
    const bool bWasOpen = IsAnyPanelOpen();
    if (bOpen) OpenPanels.Add(PanelId);
    else OpenPanels.Remove(PanelId);
    // 只有首个面板打开或最后一个面板关闭时才改变输入模式，避免反复抢焦点
    if (bWasOpen != IsAnyPanelOpen()) ApplyInputMode();
}

HUD 最终仍调用 PlayerController 的 SetInputMode 和 bShowMouseCursor，因为这些是引擎提供的玩家输入接口。面板判断已经从 PC 移出，PC 不再保存 OpenUIPanels 或 bPhoneUIOpen

来电、接听和字幕

PhoneController 初始化后订阅电话队列的 OnPhoneStateChanged。客户端的 GameState 可能尚未复制到位，此时用 0.5 秒的一次性计时器重试；连接成功就清除计时器，并读取当前电话。晚加入的玩家因此也能获得正在进行的通话内容

进入 InCall 后，处理器按 CallId 判断这通对白是否已经开始。同一状态可能分别由队列和状态字段的复制回调通知，不能因此把语音从头播放两遍。确认是新对白后，处理器读取来电者与台词，请求 DialogueVoice 播放

语音组件每读出一个字就发出 OnGlyphRevealed。处理器把这个字加入字幕，再交给 PromptSubsystem 显示。离开 InCall 时停止语音并清除字幕。处理器保存的是显示进度，实际电话状态仍以队列为准

接听和挂断由处理器的 Answer、HangUp 发起，经 PC 的原有 Server RPC 到达服务器。RPC 留在玩家拥有的 PC 上，电话队列仍在 GameState 上，原来的多人共享规则没有改变

手机关闭时铃声也会响

PhoneAudio 是 PC 上的独立组件，它自己订阅电话队列，不依赖 Widget 是否存在，也不依赖手机是否打开。进入 Ringing 开始循环铃声，离开 Ringing 停止并销毁铃声音频实例

它记录上一次已处理的通话状态，重复通知不会重复播放音效。第一次收到状态时只恢复当前铃声，不补播已经发生的接听或挂断声音

原 PC 蓝图的 PhoneToggleSound、IncomingCallSound、AnswerCallSound、HangUpCallSound 已迁移到同一蓝图的 PhoneAudio 组件中。以后在 /Game/Blueprint/PlayerController/BP_DeliveryManPC 选择 PhoneAudio 配置这四个资源

对象销毁与控制权切换

上下车只改变 Pawn，HUD、手机处理器和电话音效组件继续存在，不重新订阅电话。HUD 结束时调用处理器的 Shutdown，清除等待计时器，解除电话和语音订阅，停止对白并清空字幕

电话音效组件在自身 EndPlay 中解除电话订阅、清除重试计时器并停止铃声。UI 处理器使用弱引用访问玩家和 Model，由 HUD 的 UPROPERTY 保存处理器，既防止处理器被提前回收，也避免处理器反过来延长旧玩家的生命周期

const FName UDeliveryPhoneController::PanelId(TEXT("DeliveryPhoneUI"));

UWorld* UDeliveryPhoneController::GetWorld() const
{
    return Player.IsValid() ? Player->GetWorld() : nullptr;
}

void UDeliveryPhoneController::Initialize(ADeliveryPlayerController* InPlayer, ADeliveryHUD* InHUD)
{
    Shutdown();
    if (!InPlayer || !InPlayer->IsLocalController()) return;
    Player = InPlayer;
    HUD = InHUD;
    Voice = InPlayer->GetDialogueVoice();
    if (Voice.IsValid()) Voice->OnGlyphRevealed.AddUniqueDynamic(this, &UDeliveryPhoneController::HandleGlyph);
    BindPhone();
}

// 客户端可能先收到 HUD，稍后才收到电话队列
void UDeliveryPhoneController::BindPhone()
{
    if (!GetWorld()) return;
    Phone = UDeliveryPhoneCallQueueComponent::Get(this);
    if (!Phone.IsValid())
    {
        GetWorld()->GetTimerManager().SetTimer(BindTimer, this, &UDeliveryPhoneController::BindPhone, 0.5f, false);
        return;
    }
    GetWorld()->GetTimerManager().ClearTimer(BindTimer);
    Phone->OnPhoneStateChanged.AddUniqueDynamic(this, &UDeliveryPhoneController::HandleCallChanged);
    FDeliveryPhoneCall Call;
    if (Phone->GetCurrentCall(Call)) HandleCallChanged(Phone->GetCallState(), Call);
}

void UDeliveryPhoneController::Toggle()
{
    if (!Player.IsValid() || !HUD.IsValid()) return;
    if (auto* Audio = Player->FindComponentByClass<UDeliveryPhoneAudioComponent>()) Audio->PlayToggle();
    SetOpen(!IsOpen());
    // 现有手机蓝图通过这个事件显示或移除控件
    Player->TogglePhoneUI();
}

bool UDeliveryPhoneController::IsOpen() const
{
    return HUD.IsValid() && HUD->IsPanelOpen(PanelId);
}

void UDeliveryPhoneController::SetOpen(bool bOpen)
{
    if (HUD.IsValid()) HUD->SetPanelOpen(PanelId, bOpen);
}

void UDeliveryPhoneController::Answer()
{
    if (Player.IsValid()) Player->RequestAnswerCall();
}

void UDeliveryPhoneController::HangUp()
{
    if (Player.IsValid()) Player->RequestHangUpCall();
}

// 通话内容来自电话队列，不在界面里再保存一份任务状态
void UDeliveryPhoneController::HandleCallChanged(EDeliveryPhoneCallState State, const FDeliveryPhoneCall& Call)
{
    if (State != EDeliveryPhoneCallState::InCall)
    {
        if (Voice.IsValid()) Voice->StopSpeaking();
        ActiveCallId = 0;
        ClearSubtitle();
        return;
    }
    if (Call.CallId <= 0 || Call.CallId == ActiveCallId) return;
    ActiveCallId = Call.CallId;
    ClearSubtitle();
    const FDeliveryPhoneCallContent Content = UDeliveryPhoneCallQueueComponent::GetCallContent(Call);
    CallerName = Content.CallerName;
    if (Voice.IsValid()) Voice->SpeakText(Content.Dialogue);
}

void UDeliveryPhoneController::HandleGlyph(const FString& Glyph, int32 GlyphIndex)
{
    if (ActiveCallId <= 0) return;
    Subtitle.Append(Glyph);
    if (auto* Prompt = UDeliveryPromptSubsystem::Get(this))
        Prompt->SetSubtitle(CallerName, FText::FromString(Subtitle));
}

void UDeliveryPhoneController::ClearSubtitle()
{
    CallerName = FText::GetEmpty();
    Subtitle.Reset();
    if (auto* Prompt = UDeliveryPromptSubsystem::Get(this)) Prompt->ClearSubtitle();
}

// HUD 销毁时解除订阅，避免旧处理器继续接收新电话
void UDeliveryPhoneController::Shutdown()
{
    if (GetWorld()) GetWorld()->GetTimerManager().ClearTimer(BindTimer);
    if (Phone.IsValid()) Phone->OnPhoneStateChanged.RemoveDynamic(this, &UDeliveryPhoneController::HandleCallChanged);
    if (Voice.IsValid())
    {
        Voice->OnGlyphRevealed.RemoveDynamic(this, &UDeliveryPhoneController::HandleGlyph);
        Voice->StopSpeaking();
    }
    if (Player.IsValid()) ClearSubtitle();
    ActiveCallId = 0;
    Phone.Reset();
    Voice.Reset();
    HUD.Reset();
    Player.Reset();
}

void ADeliveryHUD::RefreshHotbar()
{
    APlayerController* Player = GetOwningPlayerController();
    if (!Player || !Player->IsLocalController()) return;
    ADeliveryCharacter* Character = ResolveCharacter(Player->GetPawn());
    if (!IsValid(Character))
    {
        // 控制对象或驾驶员尚未同步时先隐藏界面，避免继续显示旧角色的物品
        if (HotbarWidget) HotbarWidget->SetVisibility(ESlateVisibility::Collapsed);
        return;
    }
    UDeliveryInventoryComponent* Inventory = Character->GetInventoryComponent();
    if (BoundCharacter.Get() != Character)
    {
        // 更换角色时释放旧控件，同一个角色上下车则复用已有快捷栏
        RemoveHotbar();
        BoundCharacter = Character;
    }
    if (!HotbarWidget)
    {
        UClass* LoadedClass = HotbarWidgetClass.LoadSynchronous();
        if (!LoadedClass) LoadedClass = UDeliveryHotbarWidget::StaticClass();
        HotbarWidget = CreateWidget<UDeliveryHotbarWidget>(Player, LoadedClass);
        if (!HotbarWidget) return;
        HotbarWidget->SetInventory(Inventory);
        BoundInventory = Inventory;
        HotbarWidget->AddToViewport(10);
    }
    if (BoundInventory.Get() != Inventory)
    {
        HotbarWidget->SetInventory(Inventory);
        BoundInventory = Inventory;
    }
    HotbarWidget->SetVisibility(ESlateVisibility::SelfHitTestInvisible);
}

void ADeliveryHUD::RemoveHotbar()
{
    if (HotbarWidget)
    {
        HotbarWidget->SetInventory(nullptr);
        HotbarWidget->RemoveFromParent();
        HotbarWidget = nullptr;
    }
    BoundInventory.Reset();
    BoundCharacter.Reset();
}

{
    APlayerController* Player = GetOwningPlayerController();
    if (!Player || !Player->IsLocalController()) return;

        Mode.SetLockMouseToViewportBehavior(EMouseLockMode::DoNotLock);
        Mode.SetHideCursorDuringCapture(false);
        Player->SetInputMode(Mode);
    }
    else Player->SetInputMode(FInputModeGameOnly());
}

bool UDeliveryPhoneAudioComponent::IsLocalPlayer() const
{
    const auto* Player = Cast<APlayerController>(GetOwner());
    return Player && Player->IsLocalController();
}

void UDeliveryPhoneAudioComponent::BeginPlay()
{
    Super::BeginPlay();
    BindPhone();
}

void UDeliveryPhoneAudioComponent::BindPhone()
{
    if (!IsLocalPlayer()) return;
    Phone = UDeliveryPhoneCallQueueComponent::Get(this);
    if (!Phone.IsValid())
    {
        GetWorld()->GetTimerManager().SetTimer(BindTimer, this, &UDeliveryPhoneAudioComponent::BindPhone, 0.5f, false);
        return;
    }
    Phone->OnPhoneStateChanged.AddUniqueDynamic(this, &UDeliveryPhoneAudioComponent::HandleCallChanged);
    GetWorld()->GetTimerManager().ClearTimer(BindTimer);
    FDeliveryPhoneCall Call;
    if (Phone->GetCurrentCall(Call)) HandleCallChanged(Phone->GetCallState(), Call);
}

void UDeliveryPhoneAudioComponent::PlayToggle()
{
    if (IsLocalPlayer() && PhoneToggleSound) UGameplayStatics::PlaySound2D(this, PhoneToggleSound);
}

void UDeliveryPhoneAudioComponent::HandleCallChanged(EDeliveryPhoneCallState State, const FDeliveryPhoneCall& Call)
{
    if (!IsLocalPlayer() || (bHasState && State == LastState)) return;
    const bool bFirstState = !bHasState;
    const EDeliveryPhoneCallState Previous = LastState;
    bHasState = true;
    LastState = State;
    StopRinging();
    if (State == EDeliveryPhoneCallState::Ringing)
    {
        if (IncomingCallSound)
            RingAudio = UGameplayStatics::SpawnSound2D(this, IncomingCallSound, 1.f, 1.f, 0.f, nullptr, false, false);
    }
    // 晚加入时只恢复铃声，不补播已经发生的接听或挂断音效
    else if (!bFirstState && State == EDeliveryPhoneCallState::InCall && AnswerCallSound)
        UGameplayStatics::PlaySound2D(this, AnswerCallSound);
    else if (!bFirstState && State == EDeliveryPhoneCallState::Idle && Previous != State && HangUpCallSound)
        UGameplayStatics::PlaySound2D(this, HangUpCallSound);
}

void UDeliveryPhoneAudioComponent::StopRinging()
{
    if (!RingAudio) return;
    RingAudio->Stop();
    RingAudio->DestroyComponent();
    RingAudio = nullptr;
}

void UDeliveryPhoneAudioComponent::EndPlay(const EEndPlayReason::Type Reason)
{
    if (Phone.IsValid()) Phone->OnPhoneStateChanged.RemoveDynamic(this, &UDeliveryPhoneAudioComponent::HandleCallChanged);
    if (GetWorld()) GetWorld()->GetTimerManager().ClearTimer(BindTimer);
    StopRinging();
    Super::EndPlay(Reason);
}

bool ContextMapsAction(const UInputMappingContext *Context, const UInputAction *Action)
{
    if (!Context || !Action)
    {
        return false;
    }
    for (const FEnhancedActionKeyMapping &Mapping : Context->GetMappings())
    {
        if (Mapping.Action == Action)
        {
            return true;
        }
    }
    return false;
}

// 现有输入配置缺少交互操作时补充映射
void ADeliveryPlayerController::EnsureInteractMapping(UEnhancedInputLocalPlayerSubsystem *Subsystem)
{
    UInputAction *Interact = InteractAction.LoadSynchronous();
    if (!Subsystem || !Interact || !InteractKey.IsValid())
    {
        return;
    }

    // 资产里已经有映射就什么都不做——重复映射同一个动作没必要，也省得两套绑定互相干扰
    for (const UInputMappingContext *Context : DefaultMappingContexts)
    {
        if (ContextMapsAction(Context, Interact))
        {
            return;
        }
    }
    for (const UInputMappingContext *Context : MobileExcludedMappingContexts)
    {
        if (ContextMapsAction(Context, Interact))
        {
            return;
        }
    }

    if (!RuntimeInteractContext)
    {
        RuntimeInteractContext = NewObject<UInputMappingContext>(this, TEXT("RuntimeInteractContext"));
        RuntimeInteractContext->MapKey(Interact, InteractKey);
    }
    Subsystem->AddMappingContext(RuntimeInteractContext, 0);
    UE_LOG(LogDelivery, Log,
           TEXT("IMC 资产里没有 %s 的映射，已在运行时补上 %s 键。"
                "（正常情况下它应该在 IMC_Default 里，检查那个资产是不是被拉取冲掉了）"),
           *GetNameSafe(Interact), *InteractKey.ToString());
}

// 绑定手机、交互和本机界面相关按键
void ADeliveryPlayerController::SetupInputComponent()
{
    Super::SetupInputComponent();

    if (!IsLocalPlayerController())
    {
        return;
    }

    if (UEnhancedInputLocalPlayerSubsystem *Subsystem =
            ULocalPlayer::GetSubsystem<UEnhancedInputLocalPlayerSubsystem>(GetLocalPlayer()))
    {
        for (UInputMappingContext *CurrentContext : DefaultMappingContexts)
        {
            Subsystem->AddMappingContext(CurrentContext, 0);
        }

        for (UInputMappingContext *CurrentContext : MobileExcludedMappingContexts)
        {
            Subsystem->AddMappingContext(CurrentContext, 0);
        }

        EnsureInteractMapping(Subsystem);
    }

    if (auto* EnhancedInput = Cast<UEnhancedInputComponent>(InputComponent))
    {
        if (UInputAction* Action = TogglePhoneAction.LoadSynchronous())
        {
            EnhancedInput->BindAction(Action, ETriggerEvent::Started, this,
                                      &ADeliveryPlayerController::HandleTogglePhonePressed);
        }
    }
    Hints->BindInput();
}

// 确认请求者控制角色或其车辆，再转交角色交互组件
void ADeliveryPlayerController::ServerRequestInteraction_Implementation(ADeliveryCharacter *ActingCharacter,
                                                                        EDeliveryInteractionRequest Request,
                                                                        AActor *Target)
{
    if (!IsValid(ActingCharacter) || ActingCharacter->GetWorld() != GetWorld())
        return;
    const ADeliveryMotorbike *Vehicle = Cast<ADeliveryMotorbike>(GetPawn());
    // 只能操作自己当前控制的角色，或自己车辆上的驾驶员
    const bool bControlsCharacter = GetPawn() == ActingCharacter;
    const bool bControlsDriver =
        Vehicle && Vehicle->GetDriver() == ActingCharacter && ActingCharacter->GetCurrentVehicle() == Vehicle;
    if (bControlsCharacter || bControlsDriver)
    {
        ActingCharacter->GetInteractionComponent()->HandleRequest(Request, Target);
    }
}

从按下 R 到显示冷却

R 经 IMC_Default 找到 IA_SummonVehicle，输入组件在 Bind 中将动作的 Started 事件绑定到 SummonVehiclePressed。这个函数仍然检查角色能否行动，然后调用召唤组件，不负责生成车辆

召唤组件把请求送到服务器。服务器检查冷却、可用车辆和落点，成功后更新 ReadyServerTime。找不到落点或无法召唤时，不消耗冷却

// 来源：Source/Delivery/Vehicle/DeliveryVehicleSummonComponent.cpp
ReadyServerTime = Now + Cooldown;
// 房主不经过属性复制回调，因此服务器修改后也要发送通知
OnCooldownChanged.Broadcast();
Owner->ForceNetUpdate();

Cooldown 是等待时长，默认 10 秒；ReadyServerTime 是下一次允许召唤的服务器时间。结束时间只复制给操作玩家，客户端在 OnRep_ReadyServerTime 中广播 OnCooldownChanged。房主直接收到服务器上的广播

提示组件订阅这个通知后调用 RefreshHint，读取 GetCooldownRemaining，并显示向上取整的剩余秒数。它不决定能否召唤，也不修改冷却

事件怎样接到提示

事件由修改状态的代码发送，不需要提示组件每帧检查全部状态

变化 通知来源 提示组件的处理
上车、下车或重新获得角色控制权 PlayerController.OnPossessedPawnChanged HandlePawnChanged 解绑旧对象，订阅新对象，再刷新提示
切换驾驶视角 车辆 Events 发布 CameraChanged HandleVehicleEvent 调用 RefreshHint
召唤成功 服务器广播 OnCooldownChanged，客户端在复制回调中广播 RefreshHint 显示剩余秒数
输入映射重建 ControlMappingsRebuiltDelegate 重新查询当前动作对应的按键
键盘、鼠标或手柄输入 PlayerController.InputKey SetInputDevice 在设备类型变化时刷新
场景中的车辆生成或销毁 世界的 Actor 生成、销毁通知 下一帧重新检查是否可以提供召唤提示

角色变成车辆后，HandlePawnChanged 先取消订阅角色的召唤通知，再订阅车辆事件。RefreshHint 优先检查当前 Pawn 是否为摩托车，因此驾驶时显示切换视角提示，下车后恢复召唤提示

为什么倒计时仍需要计时器

开始冷却只发生一次，但界面要把 10 秒改成 9 秒、8 秒。提示组件在冷却尚未结束时设置一次计时器，到时重新读取服务器时间，并决定是否再设置下一次

// 来源：Source/Delivery/UI/DeliveryHintComponent.cpp
// 每次用服务器结束时间重算，卡顿时不会把倒计时越拖越长
GetWorld()->GetTimerManager().SetTimer(
    CountdownTimer, this, &UDeliveryHintComponent::RefreshHint,
    FMath::Max(0.01f, FMath::Min(Remaining, 1.0f)), false);

冷却结束后不再设置计时器。切换到车辆时先清除已有计时器，组件销毁时也会清除计时器和事件订阅。提示组件和召唤组件都不使用 Tick 更新提示

提示怎样显示到界面

RefreshHint 调用 ShowHint，ShowHint 把文本交给 PromptSubsystem.SetCornerHint。子系统保存文本、灰显状态和来源对象，Slate 从这些数据生成左下角显示内容

没有可显示内容时调用 ClearCornerHint，并传入当前提示组件作为来源。子系统只有在来源匹配时才清除，避免旧对象退出时误删新对象的提示。来源失效时也不显示旧文本

左下角提示不再依靠每帧推送维持显示。场景交互浮窗、任务目标和字幕仍沿用各自原来的更新规则，它们与左下角操作提示是不同的显示位置

修改和排查

改按键先打开 IMC_Default，检查动作、键盘键和手柄键。提示通过 QueryKeysMappedToAction 查询当前生效的映射，不保存一份独立的键名。当前输入设备没有对应映射时隐藏该操作提示

按键没有反应时，先看动作是否映射，再看当前控制的是角色还是车辆，最后看对应组件是否接受操作。IA 只负责传入操作，晕倒、收拳、抓取和服务器权限等条件仍由原玩法代码检查

上车后提示不对时，检查 HandlePawnChanged 是否接到新的车辆；按 P 后文字没有变化时，检查车辆是否发出 CameraChanged；召唤后没有倒计时时，检查服务器的 ReadyServerTime 和拥有者客户端的复制回调

输入缓冲未在本次增加。鼠标的 0.2 秒等待用于区分单键出拳与双键抓取，不会把收拳期间被拒绝的攻击保存为下一拳

UDeliveryHintComponent::UDeliveryHintComponent()
{
    PrimaryComponentTick.bCanEverTick = false;
    ReadyText = NSLOCTEXT("Delivery", "SummonReady", "按 {0} 召唤摩托车");
    CooldownText = NSLOCTEXT("Delivery", "SummonCooling", "召唤冷却 {0}s");
}

void UDeliveryHintComponent::BeginPlay()
{
    Super::BeginPlay();
    Player = Cast<APlayerController>(GetOwner());
    if (!Player) return;
    // 服务器切换控制对象或客户端收到新 Pawn 时，重新连接角色和车辆的通知
    Player->OnPossessedPawnChanged.AddUniqueDynamic(this, &UDeliveryHintComponent::HandlePawnChanged);
    BindInput();
    HandlePawnChanged(nullptr, Player->GetPawn());
    SpawnHandle = GetWorld()->AddOnActorSpawnedHandler(
        FOnActorSpawned::FDelegate::CreateUObject(this, &UDeliveryHintComponent::HandleVehicleChanged));
    DestroyHandle = GetWorld()->AddOnActorDestroyedHandler(
        FOnActorDestroyed::FDelegate::CreateUObject(this, &UDeliveryHintComponent::HandleVehicleChanged));
}

void UDeliveryHintComponent::BindInput()
{
    Player = Cast<APlayerController>(GetOwner());
    if (!Player || !Player->IsLocalController()) return;
    auto* NewInput = ULocalPlayer::GetSubsystem<UEnhancedInputLocalPlayerSubsystem>(Player->GetLocalPlayer());
    if (Input != NewInput)
    {
        if (Input) Input->ControlMappingsRebuiltDelegate.RemoveDynamic(this, &UDeliveryHintComponent::RefreshHint);
        Input = NewInput;
        if (Input) Input->ControlMappingsRebuiltDelegate.AddUniqueDynamic(this, &UDeliveryHintComponent::RefreshHint);
    }
    RefreshHint();
}

void UDeliveryHintComponent::UnbindPawn()
{
    if (Summon) Summon->OnCooldownChanged.RemoveDynamic(this, &UDeliveryHintComponent::RefreshHint);
    if (VehicleEvents) VehicleEvents->OnEvent.RemoveDynamic(this, &UDeliveryHintComponent::HandleVehicleEvent);
    Summon = nullptr;
    VehicleEvents = nullptr;
}

void UDeliveryHintComponent::HandlePawnChanged(APawn* OldPawn, APawn* NewPawn)
{
    UnbindPawn();
    if (auto* Character = Cast<ADeliveryCharacter>(NewPawn))
    {
        Summon = Character->FindComponentByClass<UDeliveryVehicleSummonComponent>();
        if (Summon) Summon->OnCooldownChanged.AddUniqueDynamic(this, &UDeliveryHintComponent::RefreshHint);
    }
    else if (auto* Bike = Cast<ADeliveryMotorbike>(NewPawn))
    {
        VehicleEvents = Bike->FindComponentByClass<UDeliveryEventComponent>();
        if (VehicleEvents) VehicleEvents->OnEvent.AddUniqueDynamic(this, &UDeliveryHintComponent::HandleVehicleEvent);
    }
    RefreshHint();
}

void UDeliveryHintComponent::HandleVehicleEvent(EDeliveryEvent Event)
{

        return;
    }

        GetWorld()->GetTimerManager().SetTimer(CountdownTimer, this, &UDeliveryHintComponent::RefreshHint,
                                             FMath::Max(0.01f, FMath::Min(Remaining, 1.0f)), false);
    }
    else ShowHint(FText::Format(ReadyText, Key));
}

// 等待短暂的组合键窗口，再决定出拳还是抓取
void UDeliveryInputComponent::MousePressed(bool bLeft)
{
    if (!IsValid(Character)) return;
    UDeliveryGrabComponent* GrabComponent = Character->GetGrabComponent();
    bool &ThisDown = bLeft ? bLeftMouseDown : bRightMouseDown;
    if (ThisDown)
        return;
    const bool bWasEmpty = !bLeftMouseDown && !bRightMouseDown;
    ThisDown = true;
    if (bWasEmpty)
    {
        bFirstMouseLeft = bLeft;
        bSingleMouseResolved = false;
        // 先等待另一只鼠标键；等待期间双键按下则抓取，否则按单键出拳
        GetWorld()->GetTimerManager().SetTimer(MouseChordTimer, this, &UDeliveryInputComponent::ResolveSingleMousePress,
                                        0.2f, false);
    }
    else if (!bSingleMouseResolved && !bGrabChordActive)
    {
        GetWorld()->GetTimerManager().ClearTimer(MouseChordTimer);
        bGrabChordActive = true;
        if (GrabComponent)
            GrabComponent->RequestBegin();
    }
    else if (!bGrabChordActive)
    {
        if (bLeft)
            Character->DoAttackLeft();
        else
            Character->DoAttackRight();
    }
}

// 等待结束后只处理第一次按下的键
void UDeliveryInputComponent::ResolveSingleMousePress()
{
    if (!IsValid(Character)) return;
    if (bGrabChordActive || bSingleMouseResolved)
        return;
    bSingleMouseResolved = true;
    if (bFirstMouseLeft && bLeftMouseDown)
        Character->DoAttackLeft();
    else if (!bFirstMouseLeft && bRightMouseDown)
        Character->DoAttackRight();
}

// 释放抓取，或将尚未处理的短按交给攻击入口
void UDeliveryInputComponent::MouseReleased(bool bLeft)
{
    if (!IsValid(Character)) return;
    UDeliveryGrabComponent* GrabComponent = Character->GetGrabComponent();
    bool &ThisDown = bLeft ? bLeftMouseDown : bRightMouseDown;
    if (!ThisDown)
        return;
    ThisDown = false;
    if (bGrabChordActive)
    {
        if (GrabComponent)
            GrabComponent->RequestReleaseHand(bLeft);
        if (!bLeftMouseDown && !bRightMouseDown)
            bGrabChordActive = false;
    }
    // 短按在等待结束前松开，也应执行一次攻击
    else if (!bSingleMouseResolved)
    {
        GetWorld()->GetTimerManager().ClearTimer(MouseChordTimer);
        bSingleMouseResolved = true;
        if (bLeft)
            Character->DoAttackLeft();
        else
            Character->DoAttackRight();
    }
    if (!bLeftMouseDown && !bRightMouseDown)
    {
        GetWorld()->GetTimerManager().ClearTimer(MouseChordTimer);
        bSingleMouseResolved = false;
    }
}

// 查找范围内最近的空闲摩托车
ADeliveryMotorbike* UDeliveryVehicleSummonComponent::FindSummonTarget() const
{
	UWorld* World = GetWorld();
	const AActor* Owner = GetOwner();
	if (!World || !Owner)
	{
		return nullptr;
	}

	const FVector From = Owner->GetActorLocation();
	ADeliveryMotorbike* Best = nullptr;
	float BestDistSq = TNumericLimits<float>::Max();

	for (TActorIterator<ADeliveryMotorbike> It(World); It; ++It)
	{
		ADeliveryMotorbike* Bike = *It;
		// 别人正骑着的车不能抽走
		if (!IsValid(Bike) || Bike->GetDriver() != nullptr)
		{
			continue;
		}
		const float DistSq = FVector::DistSquared(From, Bike->GetActorLocation());
		if (SearchRadius > 0.0f && DistSq > FMath::Square(SearchRadius))
		{
			continue;
		}
		if (DistSq < BestDistSq)
		{
			BestDistSq = DistSq;
			Best = Bike;
		}
	}
	return Best;
}

// 由服务器检查冷却和位置，再创建或移动车辆
void UDeliveryVehicleSummonComponent::ServerSummon_Implementation()
{
	UWorld* World = GetWorld();
	AActor* Owner = GetOwner();
	if (!World || !Owner)
	{
		return;
	}

	const float Now = World->GetTimeSeconds();
	if (Now < ReadyServerTime)
	{
		return;
	}

	// 召唤位置取玩家前方，车头保持与玩家相同的水平朝向
	const FRotator OwnerRot = Owner->GetActorRotation();
	const FVector Forward = FRotator(0.0f, OwnerRot.Yaw, 0.0f).Vector();
	const FVector Target = Owner->GetActorLocation() + Forward * PlaceDistance;

	ADeliveryMotorbike* Bike = FindSummonTarget();
	bool bSpawnedBike = false;
	if (!Bike)
	{
		// 只补地图缺车的情况；已有车被占用或超出搜索范围时不能靠新生成绕过规则
		for (TActorIterator<ADeliveryMotorbike> It(World); It; ++It)
		{
			if (IsValid(*It))
			{
				UE_LOG(LogDelivery, Log, TEXT("召唤失败：没有可召回的空闲摩托车。"));
				return;
			}
		}
		UClass* VehicleClass = DefaultVehicleClass.LoadSynchronous();
		if (!VehicleClass)
		{
			UE_LOG(LogDelivery, Warning, TEXT("召唤失败：地图没有摩托车，默认车型无法加载：%s"),
			       *DefaultVehicleClass.ToString());
			return;
		}
		FActorSpawnParameters SpawnParams;
		// SummonTo 负责探地落位；失败时销毁临时车辆，不留下空中车或消耗冷却
		SpawnParams.SpawnCollisionHandlingOverride = ESpawnActorCollisionHandlingMethod::AlwaysSpawn;
		Bike = World->SpawnActor<ADeliveryMotorbike>(VehicleClass, Target, FRotator(0.0f, OwnerRot.Yaw, 0.0f),
		                                             SpawnParams);
		if (!Bike)
		{
			UE_LOG(LogDelivery, Warning, TEXT("召唤失败：无法生成默认摩托车。"));
			return;
		}
		bSpawnedBike = true;
	}

	// 找不到可用落点时取消召唤，不消耗冷却时间
	if (!Bike->SummonTo(Target, OwnerRot.Yaw))
	{
		UE_LOG(LogDelivery, Log, TEXT("召唤失败：%s 的落点探不到地面，不计冷却。"), *Bike->GetName());
		if (bSpawnedBike)
		{
			Bike->Destroy();
		}
		return;
	}
	Bike->ForceNetUpdate();

	ReadyServerTime = Now + Cooldown;
    // 房主不经过属性复制回调，因此服务器修改后也要发送通知
    OnCooldownChanged.Broadcast();
    Owner->ForceNetUpdate();

void UDeliveryInteractionComponent::CompleteServerHold(AActor *Target)
{
    ADeliveryCharacter *Character = Cast<ADeliveryCharacter>(GetOwner());
    if (!Character || !Character->HasAuthority())
        return;

    UDeliveryInteractableComponent *Interactable = UDeliveryInteractableComponent::FindOn(Target);
    const float Now = GetWorld() ? GetWorld()->GetTimeSeconds() : 0.0f;
    // 使用服务器记录的时间检查长按时长，允许少量计时误差
    const bool bHeldLongEnough =
        Interactable && Interactable->HoldDuration > KINDA_SMALL_NUMBER &&
        Now - ServerPickupHoldStartedAt >= FMath::Max(0.0f, Interactable->HoldDuration - 0.03f);
    if (ServerPickupHoldTarget.Get() != Target || !bHeldLongEnough || !ValidateTarget(Target))
    {
        ServerPickupHoldTarget.Reset();
        return;
    }
    // 执行操作前清除记录，避免同一次长按被重复提交
    ServerPickupHoldTarget.Reset();

    if (Interactable->Pickup.IsBound())
        Interactable->Pickup.Execute(Character);
}

bool UDeliveryCarryComponent::TryReceivePackage(ADeliveryPackageItem *Package, bool bPlayFeedback)
{
    ADeliveryCharacter *Character = Cast<ADeliveryCharacter>(GetOwner());
    UDeliveryInventoryComponent *Inventory = Character ? Character->GetInventoryComponent() : nullptr;
    if (!Character)
        return false;

    if (!Character->HasAuthority() || !IsValid(Package))
    {
        return false;
    }

    // 每名玩家只能携带一件任务快递，防止手上和车上同时出现不同快递
    if (GetPackage())
    {
        return false;
    }

    UDeliveryItemComponent *Item = Package->GetDeliveryItemComponent();

    if (ADeliveryMotorbike *Bike = GetVehicle())
    {
        if (!Bike->AttachCargo(Package))
        {
            return false;
        }

        // 先把快递放到车上，再更新任务；任务不允许接取时，将快递从车辆卸下
        if (Item && !Item->NotifyAcquired(GetPlayerState()))
        {
            Bike->ReleaseCargo();

            return false;
        }

        if (bPlayFeedback)
            Character->ClientPickupSucceeded();

        return true;
    }

    // 步行时由背包接收快递，背包会同时更新任务状态
    if (Inventory && Inventory->TryPickup(Package))
    {
        if (bPlayFeedback)
            Character->ClientPickupSucceeded();

        return true;
    }

    return false;
}

bool UDeliveryTargetComponent::TryDeliver(AActor *ItemActor, APlayerState *Player)
{
    if (!GetOwner() || !GetOwner()->HasAuthority() || !CanAcceptDelivery(ItemActor, Player))
    {
        return false;
    }

    UDeliveryTaskManagerComponent *Manager = UDeliveryTaskManagerComponent::Get(this);
    if (!Manager || !Manager->TryCompleteDelivery(ExpectedTask, Player))
    {
        return false;
    }

    if (ADeliveryPackageItem *Package = Cast<ADeliveryPackageItem>(ItemActor))
    {
        ADeliveryCharacter *Holder = Cast<ADeliveryCharacter>(Package->GetOwner());
        if (const ADeliveryMotorbike *Vehicle = Cast<ADeliveryMotorbike>(Package->GetOwner()))
        {
            Holder = Vehicle->GetDriver();
        }
        if (Holder)
            Holder->GetCarryComponent()->ReleasePackage(Package);
        else if (ADeliveryMotorbike *Vehicle = Cast<ADeliveryMotorbike>(Package->GetOwner()))
            Vehicle->ReleaseCargo();
    }
    else if (ADeliveryHandheldItem *Handheld = Cast<ADeliveryHandheldItem>(ItemActor))
    {
        // 快递此刻挂在谁名下，就从那边摘干净再销毁
        // 必须摘：直接 Destroy 的话持有方还留着一个指向已销毁 Actor 的指针，
        // `HasCargo()` / 背包槽位会继续报"有货"，下一件快递就领不到了
        if (ADeliveryCharacter *Holder = Cast<ADeliveryCharacter>(Handheld->GetOwner()))
        {
            if (UDeliveryInventoryComponent *Inventory = Holder->GetInventoryComponent())
            {
                Inventory->ConsumeHeldItem(Handheld);
            }
        }
        else if (ADeliveryMotorbike *Bike = Cast<ADeliveryMotorbike>(Handheld->GetOwner()))
        {
            Bike->ReleaseCargo();
        }
    }

    ItemActor->Destroy();

    return true;
}

TArray<AActor *> UDeliveryRagdollCombatComponent::GatherHits(EMeleeHand Hand) const
{
    TArray<AActor *> Results;
    const AActor *Owner = GetOwner();
    if (!Owner || !Owner->HasAuthority() || !GetWorld())
    {
        return Results;
    }
    const FVector Center = GetPunchTraceTransform().GetLocation();
    const float Radius = GetHitRadius();

    TArray<FOverlapResult> Overlaps;
    FCollisionQueryParams Params(SCENE_QUERY_STAT(PunchHit), false, Owner);
    GetWorld()->OverlapMultiByChannel(Overlaps, Center, FQuat::Identity, ECC_PhysicsBody,
                                      FCollisionShape::MakeSphere(Radius), Params);

    for (const FOverlapResult &Overlap : Overlaps)
    {
        ADeliveryCharacter *Other = Cast<ADeliveryCharacter>(Overlap.GetActor());
        if (Other && Other != Owner && Other->GetPlayerState<ADeliverPlayerState>() &&
            Other->GetActiveRagdoll() && Other->GetActiveRagdoll()->IsRagdollActive())
        {
            // 一个角色有多个刚体，同一拳命中多个部位也只结算一次
            Results.AddUnique(Other);
        }
    }

    return Results;
}

输入处理与快捷栏管理

输入映射仍由 PlayerController 管理。角色提供输入绑定的接入点，PlayerInput 组件处理按键与鼠标组合，最终调用角色的操作入口或玩法组件。车辆保留自己的驾驶绑定，因此上车后人物和车辆不会同时接收同一组操作。

单独按下鼠标键后，输入组件等待 0.2 秒。在等待期间按下另一键，会转为抓取；等待结束后则按首次按下的键请求出拳。角色失去控制权时会清除等待状态，取消移动、抓取、长按拾取和当前出拳，之后收到松开事件也不会补发一次攻击。

快捷栏由 DeliveryHUD 创建，角色不再加载和创建控件。HUD 每 0.1 秒检查控制对象：步行时使用角色背包，骑车时使用驾驶员背包。驾驶员尚未同步时先隐藏界面；同一角色上下车复用快捷栏，更换角色后重新绑定。

HotbarController 仍负责把背包内容整理为显示数据，HotbarWidget 负责显示。这次沿用原有控件更新方式，没有改成事件通知，也没有改变手机蓝图、任务面板和交互提示的布局。

// 等待短暂的组合键窗口，再决定出拳还是抓取
void UDeliveryInputComponent::MousePressed(bool bLeft)
{
    if (!IsValid(Character)) return;
    UDeliveryGrabComponent* GrabComponent = Character->GetGrabComponent();
    bool &ThisDown = bLeft ? bLeftMouseDown : bRightMouseDown;
    if (ThisDown)
        return;
    const bool bWasEmpty = !bLeftMouseDown && !bRightMouseDown;
    ThisDown = true;
    if (bWasEmpty)
    {
        bFirstMouseLeft = bLeft;
        bSingleMouseResolved = false;
        // 先等待另一只鼠标键；等待期间双键按下则抓取，否则按单键出拳
        GetWorld()->GetTimerManager().SetTimer(MouseChordTimer, this, &UDeliveryInputComponent::ResolveSingleMousePress,
                                        0.2f, false);
    }
    else if (!bSingleMouseResolved && !bGrabChordActive)
    {
        GetWorld()->GetTimerManager().ClearTimer(MouseChordTimer);
        bGrabChordActive = true;
        if (GrabComponent)
            GrabComponent->RequestBegin();
    }
    else if (!bGrabChordActive)
    {
        if (bLeft)
            Character->DoAttackLeft();
        else
            Character->DoAttackRight();
    }
}

// 等待结束后只处理第一次按下的键
void UDeliveryInputComponent::ResolveSingleMousePress()
{
    if (!IsValid(Character)) return;
    if (bGrabChordActive || bSingleMouseResolved)
        return;
    bSingleMouseResolved = true;
    if (bFirstMouseLeft && bLeftMouseDown)
        Character->DoAttackLeft();
    else if (!bFirstMouseLeft && bRightMouseDown)
        Character->DoAttackRight();
}

// 释放抓取，或将尚未处理的短按交给攻击入口
void UDeliveryInputComponent::MouseReleased(bool bLeft)
{
    if (!IsValid(Character)) return;
    UDeliveryGrabComponent* GrabComponent = Character->GetGrabComponent();
    bool &ThisDown = bLeft ? bLeftMouseDown : bRightMouseDown;
    if (!ThisDown)
        return;
    ThisDown = false;
    if (bGrabChordActive)
    {
        if (GrabComponent)
            GrabComponent->RequestReleaseHand(bLeft);
        if (!bLeftMouseDown && !bRightMouseDown)
            bGrabChordActive = false;
    }
    // 短按在等待结束前松开，也应执行一次攻击
    else if (!bSingleMouseResolved)
    {
        GetWorld()->GetTimerManager().ClearTimer(MouseChordTimer);
        bSingleMouseResolved = true;
        if (bLeft)
            Character->DoAttackLeft();
        else
            Character->DoAttackRight();
    }
    if (!bLeftMouseDown && !bRightMouseDown)
    {
        GetWorld()->GetTimerManager().ClearTimer(MouseChordTimer);
        bSingleMouseResolved = false;
    }
}

    bLeftMouseDown = bRightMouseDown = bGrabChordActive = false;
    bSingleMouseResolved = bFirstMouseLeft = false;

    if (UDeliveryGrabComponent* Grab = OwnerCharacter->GetGrabComponent())

        if (OwnerCharacter->HasAuthority()) Grab->ForceRelease();
        else { Grab->RequestReleaseHand(true); Grab->RequestReleaseHand(false); }
    }

        Combat->CancelPunch();
}

交互组件在开始运行时登记到本世界的 DeliveryInteractionRegistry，结束时注销。注册表只保存弱引用，组件仍由所属物体管理。每个世界各有一份列表，因此同机双人运行时不会共用角色与物体引用。InteractionProbe 从中选择当前目标，范围检查和距离排序都使用实际交互位置。

公共操作使用 CanUse 检查条件、Use 执行行为。普通物品绑定自己的 Pickup，收件点绑定 CanDeliver 与 Deliver。InteractionComponent 管理按键请求、长按和服务器检查，不需要把交付当成拾取。蓝图已有按键入口保持不变。

void UDeliveryCameraComponent::PlayImpact()
{
    const APawn* Pawn = Cast<APawn>(GetOwner());
    if (!Pawn || !Pawn->IsLocallyControlled() || !Boom || !GetWorld())
    {
        return;
    }

    // 只在首次撞击时记录原距离，重复撞击不能把已拉远的距离当成原距离
    if (!bImpactActive)
    {
        BaseDistance = Boom->TargetArmLength;
        bImpactActive = true;
        SetComponentTickEnabled(true);
    }
    HoldUntil = GetWorld()->GetTimeSeconds() + GetConfig().ImpactHoldTime;
}

// 保持期间向外拉远，保持结束后回到撞击前的距离
void UDeliveryCameraComponent::TickComponent(float DeltaTime, ELevelTick TickType,
                                           FActorComponentTickFunction* ThisTickFunction)
{
    Super::TickComponent(DeltaTime, TickType, ThisTickFunction);
    if (!bImpactActive || !Boom || !GetWorld())
    {
        return;
    }
    const APawn* Pawn = Cast<APawn>(GetOwner());
    if (!Pawn || !Pawn->IsLocallyControlled())
    {
        // 切换控制对象后清除反馈，避免再次控制时留下拉远的镜头
        StopImpact();
        return;
    }

    const UDeliveryCameraConfig& Settings = GetConfig();
    const bool bHolding = GetWorld()->GetTimeSeconds() < HoldUntil;
    const float TargetDistance = BaseDistance + (bHolding ? Settings.ImpactDistance : 0.0f);
    const float Speed = bHolding ? Settings.ImpactOutSpeed : Settings.ImpactReturnSpeed;
    Boom->TargetArmLength = FMath::FInterpTo(Boom->TargetArmLength, TargetDistance, DeltaTime, Speed);

    if (!bHolding && FMath::IsNearlyEqual(Boom->TargetArmLength, BaseDistance, 1.0f))
    {
        StopImpact();
    }
}

// 精确恢复原距离，空闲时关闭更新
void UDeliveryCameraComponent::StopImpact()
{
    if (Boom)
    {
        Boom->TargetArmLength = BaseDistance;
    }
    bImpactActive = false;
    SetComponentTickEnabled(false);
}

    if (Events)

    }

void UDeliveryAudioComponent::EndPlay(const EEndPlayReason::Type EndPlayReason)
{
    if (Events)

    }

// 用事件类型查找声音，配置或声音为空时跳过播放
void UDeliveryAudioComponent::HandleEvent(EDeliveryEvent Event)
{
    if (!Config || GetNetMode() == NM_DedicatedServer)
    {
        return;
    }
    const FDeliverySoundSettings* Settings = Config->Sounds.Find(Event);
    if (Settings && Settings->Sound)
    {
        PlaySound(*Settings);
    }
}

void UDeliveryAudioComponent::PlaySound(const FDeliverySoundSettings& Settings)
{
    if (Settings.bSpatial)
    {
        UGameplayStatics::PlaySoundAtLocation(this, Settings.Sound, GetOwner()->GetActorLocation(),
                                            Settings.Volume, Settings.Pitch);
        return;
    }

    // 提示音只播放给操作玩家，服务器上的远端角色不能触发本机提示
    const APawn* Pawn = Cast<APawn>(GetOwner());
    const APlayerController* Controller = Cast<APlayerController>(GetOwner());
    if ((Pawn && Pawn->IsLocallyControlled()) || (Controller && Controller->IsLocalController()))
    {
        UGameplayStatics::PlaySound2D(this, Settings.Sound, Settings.Volume, Settings.Pitch);
    }
}

void UDeliveryVehicleAudioComponent::BeginPlay()
{
    Super::BeginPlay();
    // 按名称取得原来的发动机组件，避免误用车辆上其他声音组件
    TArray<UAudioComponent*> Components;
    GetOwner()->GetComponents(Components);
    for (UAudioComponent* Component : Components)
    {
        if (Component->GetFName() == TEXT("EngineAudio"))
        {
            EngineAudio = Component;
            EngineAudio->Stop();
            break;
        }
    }
    if (Config && !Cast<UDeliveryVehicleAudioConfig>(Config))
    {
        UE_LOG(LogDelivery, Warning, TEXT("%s 的车辆音效需要 DeliveryVehicleAudioConfig 配置"), *GetOwner()->GetName());
    }
}

// 有驾驶员时按车速调整发动机声音，没有驾驶员时停止播放
void UDeliveryVehicleAudioComponent::UpdateEngine(bool bDriving, float SpeedRatio)
{
    if (!EngineAudio || GetNetMode() == NM_DedicatedServer)
    {
        return;
    }
    const auto* Settings = Cast<UDeliveryVehicleAudioConfig>(Config);
    if (!bDriving || !Settings || !Settings->EngineSound)
    {
        if (EngineAudio->IsPlaying())
        {
            EngineAudio->Stop();
        }
        return;
    }
    if (EngineAudio->GetSound() != Settings->EngineSound)
    {
        EngineAudio->SetSound(Settings->EngineSound);
    }
    if (!EngineAudio->IsPlaying())
    {
        EngineAudio->Play();
    }
    const float Alpha = FMath::Clamp(FMath::Abs(SpeedRatio), 0.0f, 1.0f);
    EngineAudio->SetPitchMultiplier(FMath::Lerp(Settings->IdlePitch, Settings->MaxPitch, Alpha));
    EngineAudio->SetVolumeMultiplier(FMath::Lerp(Settings->IdleVolume, Settings->MaxVolume, Alpha));
}

void UDeliveryVehicleAudioComponent::EndPlay(const EEndPlayReason::Type EndPlayReason)
{
    if (EngineAudio)
    {
        EngineAudio->Stop();
    }
    Super::EndPlay(EndPlayReason);
}
